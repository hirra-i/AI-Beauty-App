AI Beauty Application
Overview
This project is a Flutter-based beauty application that combines mobile app development with AI concepts to provide personalised beauty recommendations. The application was 
developed as part of my interest in both technology and beauty, allowing me to explore mobile development, user experience design, and AI integration.

- Features
User-friendly mobile interface
Personalised beauty recommendations
AI integration using OpenAI
Modern Flutter UI
Firebase backend integration
Cross-platform mobile development

- Technologies Used
Flutter
Dart
Firebase
OpenAI
Python
Git & GitHub
Visual Studio Code

- Future Improvements
Enhanced AI recommendations
User accounts and profiles
Improved UI/UX design
Additional beauty analysis features
App Store and Google Play deployment
